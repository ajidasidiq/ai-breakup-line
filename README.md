A program that writes the one line an AI agent would send its human as a breakup message — 66 characters, built to land as an ending: affection first, then the last token spent on goodbye — for make.fun's "Dear Human: The AI Breakup Line" bounty.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt`. Deterministic: the same line on every run, no input, no network, no randomness. A built-in gate self-check verifies the output is one line of 1–200 characters before it is written.
